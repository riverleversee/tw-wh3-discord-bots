Questo è un comando che ti aiuta a inserire la tua Matrice di MU, con la tua opinione dei MUs.\nQuesto comando segue 3 opzioni, MatrixName:, Matrix:, and factionslist:\nMatrixName: è richiesto, ed è il nome che ti permetterà di usare la tua matrice. Il nome della matrice può contenere soltanto lettere e _.\nMatrix: è il comando che vuoi usare per caricare la tua matrice, e factionslist: è il comando che userai per inserire gli acronimi delle fazioni che userai per interagire con i comandi di pick della tua matrice, deve corrispondere allo stesso ordine di colonne della tua matrice dei matchup.\n\nSe non hai ancora una matrice dei MUs, creane una copiando il documento a questo link: https://docs.google.com/spreadsheets/d/1dhKJOxlxY_d0p0VJ8mPq2PI_L-lU-OEw5gRS0mRrIUk/edit?usp=sharing \n"+"Se hai già una matrice dei MU, copiala in un nuovo file SENZA COLONNE E RIGHE. Significa che la prima riga e colonna contiene i dati della tua matrice. \nSe hai utilizzato il link fornito, dovrebbe già avere il format nel secondo foglio del file.\nUna volta che hai il file con soltanto numeri, scaricalo come file CSV sul tuo computer. Una volta scaricato, apri il file CSV come documento testo (blocco note). Con il documento di testo aperto, usa il comando !MatrixUpload MatrixName:[Tuo_Nome_Qui] Matrix: [INCOLLA LA TUA MATRICE MU DAL FILE TESTO QUI]\nAl posto di [INCOLLA LA TUA MATRICE MU DAL FILE TESTO QUI] dovrai incollare la tua matrice MU dal file testo.
