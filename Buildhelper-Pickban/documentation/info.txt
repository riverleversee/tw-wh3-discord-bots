This is a bot to help you decide your picks and bans for TWW:3. Pick/ban commands are numerically optimized decision helpers: they search a matchup matrix under your constraints (unplayable factions, global bans, series history, must-include, avoid lists, etc.) and return optimal pick and ban options with expected matchup outcomes. The bot also tracks and analyzes faction winrate stats and gives new players build advice created by veterans. \nThe avaliable commands are: \n!pick3\n!pick2 \n!pick1\n!counterpick3\n!counterpick2 \n!matrixupload \n!factions \n!factionstats \n!updatestats\n!MUhelp \n!updateMUhelp\nTo use a command in general you start with an ! followed by the command name. \nThe command name is then followed by some options in the format ![command name] [option name]: [option here]\nThere is more info about each command's options inside the info about the specific commands.\nUse !info[command name] (i.e. !infopick3) to get more information about each command.\n

There is also language implementations for Spanish and Italian in progress. To use a language option for spanish add "LANG: ESP" to the end of the command or "LANG: ITL" for Italian.
Per la versione in lingua italiana utilizzare il comando: "!info LANG: ITL"
Para la versión en italiano utilice el comando: "!info LANG: ESP"
