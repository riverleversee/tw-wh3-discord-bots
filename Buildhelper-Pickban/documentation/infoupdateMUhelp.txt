This is a command to update the build advice for new players!
To use this command input "!updateMUhelp MU: F1vsF2 newline: [PUT ANY NEW TEXT YOU WANT HERE (with no brackets)]"

Where F1 and F2 are faction acronyms for the factions being updated. For example, "!updateMUhelp MU: DWvsGS newline: [TEXT HERE]" to update the Dwarf section of Dwarf vs Greenskins.
To get a full list of the acceptable faction acronyms use the command !factions.
If you need to update a section for a language other than english use the command "!updateMUhelp MU: F1vsF2 LANG: ESP newline: [TEXT HERE]" for spanish,  "!updateMUhelp MU: F1vsF2 LANG: ITL newline: [TEXT HERE]" for Italian to update the translated version.
To update the Domination mode section use the command "!updateMUhelp MU: DWvsGS Mode: DOM newline: [TEXT HERE]", where the added Mode: DOM specifies that it is information for domination mode.
Not all users have the ability to use this command, if you need permission please ask a server admin for it.
At this time you cannot upload images, for security reasons, please DM any images you need updated to a server admin. 

If you need to update more than 2000 Characters take the following steps:
1. Upload your first section normally using "!updateMUhelp MU: F1vsF2 newline: [PUT ANY NEW TEXT YOU WANT HERE (with no brackets)]"
2. Execute the command "!MUhelp MU: F1vsF2" 
3. See how many times the bot sends a message i.e. how many different chunks of text there are where iy becomes shaded when you hover over them with your mouse. 
4. "!updateMUhelp MU: F1vsF2 linenumber: # newline: [PUT ANY NEW TEXT YOU WANT HERE (with no brackets)]" Use this command where the linenumber is the number you counted in set 3. 
5. Check the result using "!MUhelp MU: F1vsF2"
