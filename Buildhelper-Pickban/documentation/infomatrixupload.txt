This is a command to help you upload your own MU matrix with you opinions of MUs.\nThis command takes 3 options, MatrixName:, Matrix:, and factionslist:\nMatrixName: is required, and is the name you will later use to call for your matrix to be used. The matrix name can only contain letters, and _.\nMatrix: is the command you will use to upload your matrix, and factionslist: is the command you will use to upload the faction acronyms you will use when interacting with the pick command for your matrix, and must be in the same order corresponding to the order of the columns in your match up matrix.\n\nIf you do not already have a matrix of MUs please create one by copying the document in this link: https://docs.google.com/spreadsheets/d/1dhKJOxlxY_d0p0VJ8mPq2PI_L-lU-OEw5gRS0mRrIUk/edit?usp=sharing \n"+"If you already have a MU matrix then please copy it to a new spreadsheet with NO COLUMN OR ROW LABELS. This means the first row and column contain entries from your matrix. \nIf you used the link provided, it should already have this format as the second sheet in the file.\nOnce you have this spreadsheet with just numbers, download this as a CSV file to your computer. Once downloaded, open the CSV file as a text document (i.e. in notepad). With the text document open you will now use the command !MatrixUpload MatrixName:[Your_Name_Here] Matrix: [PASTE YOUR MU MATRIX FROM THE TEXT FILE HERE]\nIn the place of [PASTE YOUR MU MATRIX FROM THE TEXT FILE HERE] you will paste your MU matrix from the text file. If there is a row of all commas (i.e. ,,,,,,,,) do not copy that row.\nIf the upload is successful the bot will tell you so, if there is a formatting issue the bot will also tell you.\nNow that the matrix is uploaded you need to upload your list of faction names/acronyms.\nThis command will be in the format (where you should be sure to use the same name as the matrix) !MatrixUpload MatrixName:[Your_Name_Here] factionslist: [PASTE YOUR LIST OF FACTIONS HERE]\nIn the place of [PASTE YOUR LIST OF FACTIONS HERE] you will need to list your factions in the form [Faction 1],[Faction 2],[Faction 3]... in the same order as the column labels from your MU matrix.
